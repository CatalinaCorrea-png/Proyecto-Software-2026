⚠

El problema hoy

Equipos a pie cubriendo terreno celda por celda, sin capacidad de vision nocturna ni termica, con comunicacion precaria y fatiga acumulada. Las aeronaves tripuladas son caras y no siempre estan disponibles.

💡

Nuestra propuesta

Un drone autonomo con camara RGB y simulacion termica que recorre una grilla de busqueda de forma sistematica, detecta personas con inteligencia artificial (YOLO) y envia alertas geolocalizadas en tiempo real a un centro de comando web.

05 / 08
EL PRODUCTO

Funcionalidades principales

Lo que el sistema hace de punta a punta

📡

Telemetria en tiempo real

Posicion GPS, altitud, velocidad, bateria y estado del drone por WebSocket. Compatible con telemetria real del ESP32 y modo simulado.

🤖

Deteccion con IA (YOLO + Termica)

YOLOv8 sobre frames RGB + simulacion termica. Fusion de ambas fuentes para clasificar confianza en high, medium o low.

🗺

Mapa interactivo con grilla

Leaflet con trail de vuelo, grilla de cobertura (unexplored / explored / detection) y marcadores de capturas geolocalizadas.

🎮

Control manual del drone

Joystick virtual para throttle, pitch y roll. Comandos UDP al ESP32 en tiempo real. Modos automatico, manual y hover.

📸

Galeria de capturas

Guardado automatico en MongoDB al detectar personas. Thumbnails, filtrado por mision y modal de detalle con bounding boxes.

📊

Historial y estadisticas

Registro de misiones con cobertura, detecciones y bateria. Dashboard con graficos Recharts: evoluciones, distribuciones y comparativas.

📷

Video multi-fuente

Webcam, MJPEG del ESP32-CAM, archivos de video en rotacion o YouTube. Cambiable por config sin tocar codigo.

🐳

Deploy con Docker Compose

Un solo comando levanta backend, frontend (nginx) y MongoDB. Healthchecks, volumenes persistentes y variables de entorno.

06 / 08
EL PRODUCTO

Flujo de una mision

Desde la configuracion hasta el reporte final

1

Configurar mision

El operador define nombre, coordenadas GPS de inicio, altitud de vuelo, y tamano de grilla (filas x columnas x tamano de celda). Presets rapidos para ubicaciones frecuentes (UNSAM, Aconcagua, Plaza de Mayo).

2

Vuelo y barrido

El drone (real o simulado) recorre la grilla en patron serpentina. La telemetria se transmite por WebSocket cada segundo. El mapa muestra el trail y pinta las celdas a medida que se exploran. El operador puede tomar control manual en cualquier momento con el joystick.

3

Deteccion en tiempo real

Cada frame pasa por YOLO (RGB) y el simulador termico en paralelo (asyncio.to_thread). La fusion clasifica la confianza. Si es medium o high, se dispara una alerta con posicion GPS, se marca la celda en el mapa, se guarda la imagen anotada en MongoDB y el registro en SQLite.

4

Reporte y analisis

Al finalizar la mision se guardan cobertura, bateria final y todas las detecciones. El historial permite revisar cada mision. La galeria muestra las capturas con bounding boxes. El dashboard de estadisticas grafica tendencias, distribuciones y comparativas entre misiones.

07 / 08
APRENDIZAJES

Lo que nos llevamos

Lecciones tecnicas y de equipo que quedan mas alla del proyecto

🔄

Scrum en la practica

Planificar sprints cortos, hacer reviews al final de cada uno y adaptarse cuando algo no salia como esperabamos. El backlog vivo es mas util que un plan rigido de 4 meses.

🔗

Integracion full-stack real

Conectar React con FastAPI con WebSocket, manejar CORS, serializar datos binarios (frames JPEG en base64) y mantener estado sincronizado entre cliente y servidor.

🧠

IA aplicada con restricciones

Usar YOLO no es solo importar la libreria: elegir pesos, correr inferencia sin bloquear el event loop (asyncio.to_thread), dibujar anotaciones y fusionar con otra fuente de datos.

📡

Comunicacion IoT

Protocolos UDP para baja latencia vs WebSocket para datos estructurados. Manejar reconexiones, timeouts, keepalives y la diferencia entre telemetria real del ESP32 y simulada.

🗄

Elegir la base de datos correcta

SQLite para datos relacionales (misiones, detecciones, celdas) y MongoDB para datos binarios grandes (imagenes con thumbnails). Cada herramienta en lo que hace mejor.

🤝

Trabajar en equipo de verdad

6 personas tocando el mismo repo. Branches, merge conflicts, code reviews, dividir tareas sin pisar el trabajo del otro. Comunicarse cuando algo se rompe en vez de arreglarlo solo.

🐳

DevOps y despliegue

Docker Compose para que cualquiera levante el proyecto entero con un comando. Healthchecks, volumenes, variables de entorno y la diferencia entre desarrollo y produccion.

🐛

Debuggear lo invisible

Problemas de puertos UDP ocupados al reiniciar (WinError 10048), frames que llegan vacios, GPS sin fix, misiones huerfanas en la base. Los bugs mas dificiles son los que no tiran error.
